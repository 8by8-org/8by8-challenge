# Testing

## Overview

This document outlines how testing is implemented in the 8by8 project, including frameworks, local setup, CI/CD execution, code coverage, and helpful utilities.

---

## Testing Frameworks

We use the following tools:

- **Jest** – JavaScript testing framework for unit tests
- **React Testing Library** – For testing React components
- **JSDOM** – Browser simulation for Jest environment
- **Selenium** – For end-to-end testing in staging
